# automated-todoist-task-planner

Automated task planner for Todoist that continuously re-evaluates tasks, priorities, durations, due dates, and fixed constraints to build and maintain a schedule inside a user-defined productivity window.

## Setup

1. Copy `.env_example` to `.env` and fill in the required values.
2. Install dependencies:

```bash
pdm install
```

## Testing

Run the test suite with:

```bash
pdm run test
```

To compare different scheduling methods, run:

```bash
pdm run test_comp
```

## Real Todoist Setup

To connect the application to a real Todoist account, you need two Todoist accounts on Pro plans so task durations can be used: one primary account that contains the tasks to be scheduled, and a second "bot" account that the application uses to communicate with Todoist. You also need `cloudflared` installed so Todoist webhooks can reach the local application.

1. Share the folder containing the tasks to be auto-planned with the second "bot" Todoist account: https://www.todoist.com/help/articles/collaborate-with-friends-or-family-in-todoist-tzkGUy
2. Create a Cloudflare Tunnel to receive Todoist webhooks:

```bash
cloudflared tunnel --url http://localhost:8080
```

3. Configure the webhook in Todoist. Open Todoist, go to Settings -> Integrations -> Developer -> App Management -> Add new integration, fill in the form, then open the created integration. In Webhooks -> Webhook Events, enable all scopes starting with `item:`, paste the URL generated by `cloudflared` into Callback URL, then update and save the webhook.
4. Generate an API token for the "bot" Todoist account. Open the bot account, go to Settings -> Integrations -> Developer, and copy the API token.
5. Paste the token into the `.env` file.
6. Run the application:

```bash
pdm run start
```

## Project structure

- `automated_todoist_task_planner` - main folder containing the code
    - `planners` - subfolder containing code related specifically to planning
- `scripts/` - Utility scripts.
- `task_seeds` - files containing lists of tasks to be scheduled; used for evaluation and testing
- `tests` - test and evaluation related code
